# NDEX
Automated device firmware search tool.

NDEX is a webui landing page for easy setup, connection and integration between devices of all hardware types and base operating systems, it integrates a webflasher to auto detect a connected device and assign it's role and firmware package, while providing a headscale/tailscale integration to connect all devices and services.

It displays a carousel of "workspaces" that each represent a connected peer, device, or service.
